# 작업 흐름과 작업 구간

## 기본 흐름

```
이슈 발행 → 브랜치 생성 → 작업·커밋 → PR 작성 → 셀프 리뷰 → Squash 머지 → 이슈 자동 종료
```

1. **이슈 발행**: `.github/ISSUE_TEMPLATE/`에서 맞는 템플릿을 고릅니다. 완료 조건을 먼저 적습니다.
2. **브랜치 생성**: `main`에서 분기합니다.
   ```bash
   git switch main && git pull
   git switch -c feat/#4-hero
   ```
3. **작업·커밋**: 커밋 하나에 변경 하나만 담습니다. `docs/01-commit-convention.md`를 따릅니다.
4. **PR 작성**: 템플릿의 셀프 리뷰 체크리스트를 모두 확인합니다. 본문에 `closes #4`를 넣습니다.
5. **머지**: Squash 머지 후 브랜치를 삭제합니다.

## 브랜치 이름

`<type>/#<이슈번호>-<영역>`

예: `feat/#7-animals`, `fix/#11-mobile-menu`, `a11y/#13-focus`, `chore/#1-setup`

## 선택 작업 (시간 여유가 있을 때)

- 입양 절차 아코디언 (`<details>`)
- 동물 카드 상세 모달 (`<dialog>`)
- 현재 보고 있는 섹션을 내비게이션에 표시 (`IntersectionObserver` + `aria-current`)

선택 작업도 같은 흐름(이슈 → 브랜치 → PR)으로 진행합니다.
